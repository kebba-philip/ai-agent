# Calculator

The calculator evaluates mathematical expressions and renders the result to the console.

The AI agent can interact with the calculator using its tools:

1. **`get_files_info`** — Lists the calculator's files and directories.
2. **`get_file_content`** — Reads the calculator's source code.
3. **`write_file`** — Creates or modifies calculator files.
4. **`run_python_file`** — Executes Python files such as `tests.py`.
